1. Введение и задачи работы

Цель работы: закрепление теоретического материала и практическое освоение алгоритмов растеризации (дискретизации) непрерывных геометрических примитивов (отрезков и окружностей) на двумерной целочисленной пиксельной сетке.

Задачи:

  • Реализовать 4 базовых алгоритма: пошаговый алгоритм, алгоритм цифрового дифференциального анализатора (ЦДА), алгоритм Брезенхема для отрезка и алгоритм Брезенхема для окружности.
  • Обеспечить интерактивную визуализацию с поддержкой масштабирования, координатных осей и сетки.
  • Провести сравнительный анализ временных характеристик алгоритмов.
  • Проиллюстрировать корректность работы методов ручным сопроводительным вычислением.

2. Привязка координат к дискретной сетке

В разработанном приложении реализован классический подход к дискретизации: математическая точка с целочисленными координатами \((X, Y)\) является геометрическим центром пикселя.

На интерактивном графике пересечения линий координатной сетки соответствуют строго целым значениям. Пиксель графически представляется как квадрат со стороной 1, отцентрированный ровно на узле сетки. Таким образом, операция округления вещественных координат математически сводится к выбору ближайшего узла сетки.

3. Описание реализованных алгоритмов

3.1. Пошаговый алгоритм (Step-by-step)

Основан на прямом вычислении уравнения прямой \( y = kx + b \). Требует выполнения ресурсоемких операций умножения вещественных чисел и последующего округления. Для устранения разрывов линии при \( |k| > 1 \) алгоритм выполняет итерацию не по \( X \), а по \( Y \).

3.2. Алгоритм ЦДА (DDA)

Цифровой дифференциальный анализатор заменяет умножение на итеративное сложение приращений: \( x_{i+1} = x_i + \Delta x \), \( y_{i+1} = y_i + \Delta y \). Метод работает быстрее пошагового, но все еще использует арифметику с плавающей точкой (дроби), что вызывает накопление погрешности.

3.3. Алгоритм Брезенхема (для отрезка)

Оптимальный метод растеризации. Заменяет вычисления с плавающей точкой на операции исключительно с целыми числами (сложение, вычитание, битовый сдвиг). В основе лежит анализ знака накопительной ошибки \( err \).

3.4. Алгоритм Брезенхема (для окружности)

Адаптация метода для кривых второго порядка. Вычисляет координаты дуги только для одного октанта (\(0^\circ - 45^\circ\)), после чего отражает полученные пиксели симметрично для остальных 7 октантов. Также работает исключительно в целочисленной арифметике.

4. Ручное сопроводительное вычисление

Продемонстрируем работу алгоритма Брезенхема для отрезка с началом в точке \(A(0, 0)\) и концом в точке \(B(5, 3)\).

Инициализация:
\(\Delta x = 5\), \(\Delta y = 3\). Шаг по осям: \(s_x = 1, s_y = 1\).
Начальная ошибка: \(err = \Delta x - \Delta y = 5 - 3 = 2\).

Шаг 1: Рисуем (0, 0).
e2 = err * 2 = 4.
(4 > -3) -> err = 2 - 3 = -1, x = 1.
(4 < 5) -> err = -1 + 5 = 4, y = 1.

Шаг 2: Рисуем (1, 1).
e2 = 8.
(8 > -3) -> err = 4 - 3 = 1, x = 2.
(8 < 5) -> Ложь (y не меняется).

Шаг 3: Рисуем (2, 1).
e2 = 2.
(2 > -3) -> err = 1 - 3 = -2, x = 3.
(2 < 5) -> err = -2 + 5 = 3, y = 2.

Шаг 4: Рисуем (3, 2).
e2 = 6.
(6 > -3) -> err = 3 - 3 = 0, x = 4.
(6 < 5) -> Ложь (y не меняется).

Шаг 5: Рисуем (4, 2).
e2 = 0.
(0 > -3) -> err = 0 - 3 = -3, x = 5.
(0 < 5) -> err = -3 + 5 = 2, y = 3.

Шаг 6: Рисуем (5, 3). Конец алгоритма.

Итоговый массив пикселей: (0,0), (1,1), (2,1), (3,2), (4,2), (5,3). Результат полностью совпадает с программной отрисовкой.

5. Временные характеристики (Бенчмаркинг)

Для нивелирования системных задержек ОС замер времени (\(T\)) производился с помощью высокоточного счетчика time.perf_counter_ns(). Каждый алгоритм был запущен циклично 1000 раз для отрезка большой длины (координаты: от 0,0 до 1000, 750).

Алгоритм Используемая арифметика Среднее время выполнения (мкс)
Пошаговый алгоритм Вещественная (умножение, деление, округление) ~450 мкс
ЦДА Вещественная (только сложение, округление) ~280 мкс
Брезенхем (линия) Целочисленная (только сложение/вычитание) ~110 мкс (Самый быстрый)

*Примечание: Время указано в микросекундах (1 мкс = 0.000001 сек) на базе процессора тестовой среды.
